# QRUngu

A free QR code maker for UiTM clubs and associations. Make poster-ready QR codes right in the browser. No sign-up, no install, no server.

**Live site:** https://dxnieldev.github.io/qrungu

## What it can do

Make a QR code for:

- **Links**: event registration forms, Google Forms, Linktree, websites, WhatsApp and Telegram group invites
- **WhatsApp**: open a chat with a number, with an optional pre-filled message
- **Instagram**: send people to your club's page from a username
- **Telegram**: send people to a channel or username
- **Email**: open a draft with the address and subject filled in
- **Text**: any plain text, such as a code or a matric number

## Features

- Type a username or phone number instead of a full URL
- Malaysian numbers like `012-345 6789` are converted to the international format
- Links without `https://` still work
- Live preview that updates as you type
- Shows the exact link or text the QR will open, with a Copy button
- Club logo in the centre, with high error correction so the code still scans
- Caption and small text under the QR, for example "Kelab Komputer UiTM" and "Scan to register"
- Five colour presets
- Warnings for low contrast and for very long content
- Download as PNG, SVG or PDF
- Light and dark theme that follows your device
- Works on phones and desktops
- Runs fully in your browser. Links and logos are never uploaded.
